# 🎯 Number Guessing Game

A simple command-line game built with Python. The computer randomly selects an integer between **0 and 100**, and you have **10 valid attempts** to guess it.

## 🎮 How to Play

1. Run the program.
2. Enter a whole number between `0` and `100`.
3. Follow the hints:
   - **Too low:** Guess a higher number.
   - **Too high:** Guess a lower number.
4. Guess correctly to win. Use all 10 attempts and the game is over—the secret number will be revealed.

Invalid entries do not consume an attempt. This includes non-numeric input, decimal values, and numbers outside the allowed range. The remaining attempts are shown in the input prompt. You can also stop the game safely with `Ctrl+C` or by closing the input stream.

## ⚙️ Requirements

- Python 3
- No external packages required.

## ▶️ Run

From this directory, run:

```bash
python main.py
```

# 🎯 بازی حدس عدد

یک بازی ساده متنی با Python که در آن کامپیوتر به‌صورت تصادفی یک عدد صحیح بین **۰ تا ۱۰۰** انتخاب می‌کند و شما **۱۰ فرصت معتبر** برای حدس زدن آن دارید.

## 🎮 نحوه بازی

۱. برنامه را اجرا کنید.
۲. یک عدد صحیح بین `0` تا `100` وارد کنید.
۳. از راهنمایی‌ها استفاده کنید:

- **Too low:** عدد انتخابی کمتر از عدد مورد نظر است؛ عدد بزرگ‌تری وارد کنید.
- **Too high:** عدد انتخابی بیشتر از عدد مورد نظر است؛ عدد کوچک‌تری وارد کنید.
  ۴. با حدس درست برنده می‌شوید. اگر هر ۱۰ فرصت تمام شود، بازی به پایان می‌رسد و عدد صحیح نمایش داده می‌شود.

ورودی نامعتبر از تعداد فرصت‌ها کم نمی‌کند. این مورد شامل ورودی غیرعددی، عدد اعشاری و اعداد خارج از محدوده مجاز است. تعداد فرصت‌های باقی‌مانده در کنار پیام دریافت ورودی نمایش داده می‌شود. همچنین می‌توانید با `Ctrl+C` یا بسته شدن ورودی، بازی را بدون خطای ناخواسته متوقف کنید.

## ⚙️ پیش‌نیازها

- Python 3
- بدون نیاز به نصب کتابخانه جانبی

## ▶️ اجرا

در ترمینال و از مسیر همین پوشه اجرا کنید:

```bash
python main.py
```
